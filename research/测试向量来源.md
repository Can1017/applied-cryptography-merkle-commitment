# NIST 测试向量来源


官方入口：[NIST CAVP Secure Hashing](https://csrc.nist.gov/projects/cryptographic-algorithm-validation-program/secure-hashing)。只使用 byte-oriented 已知答案数据；未运行任何参考哈希实现。

| 官方归档 | 提取的数据文件 | 记录数 |
| --- | --- | ---: |
| [SHA-2 byte vectors](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/shabytetestvectors.zip) | SHA256ShortMsg.rsp | 65 |
| 同上 | SHA256LongMsg.rsp | 64 |
| [SHA-3 byte vectors](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/sha3/sha-3bytetestvectors.zip) | SHA3_256ShortMsg.rsp | 137 |
| 同上 | SHA3_256LongMsg.rsp | 100 |

归档分别为 4,909,729 字节、2,801,880 字节；只将表中四个原始 `.rsp` 文件提取到 `tests/vectors/`，测试逐条读取输入和预期摘要。没有对数据文件进行改写，也没有使用 Monte Carlo 文件。Len=0 时，文件中的 Msg=00 是占位表示，测试按真正空字节串处理。

额外计算示例来自 [NIST SHA-256 示例](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Standards-and-Guidelines/documents/examples/SHA256.pdf)（abc、56 字节消息）和 [NIST SHA3-256 1600-bit 示例](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Standards-and-Guidelines/documents/examples/SHA3-256_1600.pdf)（200 个 A3 字节）。

已知答案数据不是哈希函数实现。整个测试过程不调用 `hashlib`、OpenSSL、系统摘要命令或现成 Merkle 库。通过这些向量只是课程实现的验证证据，不代表通过 NIST CAVP 认证。

如需重新提取，先将两个官方 ZIP 放在 `research/`，再执行 `python scripts/prepare_vectors.py`。运行现有测试无需 ZIP、网络或下载步骤。
